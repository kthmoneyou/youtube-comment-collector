수집 범위와 개수는 어떻게 정해지나요?

공식 YouTube Data API로 접근할 수 있는 공개 댓글만 가져옵니다. 삭제·비공개·검토 대기 댓글, 실시간 채팅은 포함하지 않습니다. 답글이 많은 영상은 요청 횟수가 늘어납니다. 한 번에 최대 20개 영상, 영상당 최대 5,000개, 총 API 요청 500회까지 지원합니다. 개수 한도에 도달하거나 중지·오류가 발생하면 일부 결과만 남을 수 있으며, 영상별 상태에 표시합니다. ‘완료’도 수집 시점에 API가 반환한 범위를 뜻하므로 유튜브 화면의 댓글 수와 다를 수 있습니다. 좋아요순은 가져온 결과 안에서만 정렬합니다.

개인정보와 다운로드 안내

이 도구는 YouTube와 별개인 독립 도구이며 YouTube Data API Services를 사용합니다. 입력한 API 키와 영상 ID는 Google API로 직접 전송됩니다. 댓글 내용·작성자 이름·날짜·좋아요 수는 현재 탭의 메모리에만 보관합니다. 별도 서버 저장, 광고, 분석 추적, 브라우저 저장소 사용은 없습니다. GitHub Pages와 Google은 요청 처리 과정에서 자체 정책에 따라 접속 정보를 처리할 수 있습니다. 새로고침 또는 탭 닫기로 키와 수집 결과가 제거됩니다. CSV는 현재 검색·유형 필터에 맞는 모든 결과를 내려받으며 한글 엑셀 호환 UTF-8 형식입니다. 셀 수식 실행 방지를 위해 특수문자로 시작하는 텍스트에는 작은따옴표가 추가될 수 있습니다. 내려받은 파일은 직접 보관·삭제해 주세요. Google 개인정보처리방침 · YouTube 이용약관
